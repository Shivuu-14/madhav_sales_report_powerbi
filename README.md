# madhav_sales_report_powerbi

Developed an interactive Power BI dashboard to analyze e-commerce sales, profit, quantity, and average
order value (AOV) across multiple dimensions.
◦ Implemented DAX measures to calculate KPIs such as Total Sales, Total Profit, Quantity Sold, AOV, and
monthly profit trends.
◦ Visualized insights by state, category, sub-category, customer, and payment mode, enabling identification
of high-profit segments and loss-making months.
